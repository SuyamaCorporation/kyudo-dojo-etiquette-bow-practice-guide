# 弓道 道場礼法・行射工程ガイド

弓道の礼法・射法八節・段級審査基準を3タブ構成でまとめたガイドアプリです。立礼・座礼・道場入退出の手順をチェックリストで確認でき、射法八節は各動作の詳細説明・よくある間違い・チェックポイントを開閉式パネルで表示します。練習チェックの状態はlocalStorageに保存され、次回起動時も引き継がれます。

## 機能
- 礼法タブ：立礼・座礼・道場入退出の手順チェックリスト（localStorage保存）
- 射法八節タブ：8動作の詳細説明・NG例・チェックポイントを折りたたみ表示
- 射法八節の練習チェックリスト（localStorage保存）
- 審査基準タブ：初段〜五段の必要条件・審査内容一覧表
- 段位別自己評価チェックリスト（localStorage保存）
- 各タブのチェックリセットボタン
